Looking back

Learning & Reflection

Skills Developed

Through this project, I improved my HTML, CSS and JavaScript skills. I learned how to create responsive layouts, style reusable components and add interactive features. Working with my team also strengthened my communication, time-management and problem-solving skills.

Challenge Faced

One challenge I faced was keeping the design consistent across different pages and screen sizes. I addressed this by using CSS variables, Grid, Flexbox and media queries. I also tested the website regularly and adjusted elements that overflowed or appeared incorrectly.

Future Improvement

With more time, I would improve the website's accessibility, add more detailed project content and conduct further testing on different devices and browsers. I would also optimise the images to improve the website's loading speed and overall performance.

This project gave me practical experience in planning, designing and developing a complete website. It also helped me understand the importance of teamwork, testing and continuous improvement throughout the development process.
